# Сигнал
Учебный сайт музыкальной группы на React и TypeScript. Общий чат участников, регистрация, вход, выход и профиль музыканта. Пока идёт запрос, сверху отображается плашка, а кнопки формы блокируются.

## Запуск
Распакуйте архив. В терминале из папки с package.json выполните с Node.js 22.12 или новее:
```bash
npm ci
npm run dev
```
Откройте адрес, который напечатает Vite. Для проверки типов и production-сборки выполните `npm run build`.

## Как работает авторизация и чат
Клиент обращается к https://inai-col3.fishrungames.com/api/. Swagger доступен по адресу https://inai-col3.fishrungames.com/api/docs/. Методы регистрации и входа принимают username и password. Access-токен из ответа хранится в текущей вкладке. Refresh-токен хранит сервер в HttpOnly cookie. Для профиля клиент передаёт заголовок Authorization: Bearer с access-токеном.

После входа открывается соединение с wss://inai-col3.fishrungames.com/chat/. Первым кадром отправляется AUTH c токеном. Только AUTH_SUCCESS разблокирует отправку CHAT_MESSAGE. В ленте отображаются NEW_MESSAGE от сервера с именем отправителя и временем. При обрыве доступно повторное подключение. История отображает сообщения, полученные в текущем сеансе. При успешном выходе клиент закрывает сокет и очищает токен.

В src/api.ts находятся HTTP-запросы, в src/Chat.tsx — WebSocket и лента, в src/main.tsx — формы и профиль.

## Публикация
1. Поместите содержимое папки Дз10 в корень своего репозитория, включая .github/workflows/pages.yml. package.json должен лежать в корне.
2. В Settings → Pages → Build and deployment выберите GitHub Actions.
3. Отправьте изменения в ветку main. Если файлы уже там, откройте Actions → Publish to GitHub Pages → Run workflow.
4. После успешного задания deploy откройте ссылку в Settings → Pages.

## Автор коммитов
Перед первым коммитом в своём репозитории выполните команды со своими реальными данными. Используйте email, привязанный к вашему GitHub, либо ваш GitHub noreply-адрес.
```bash
git config --local user.name "Ваше имя"
git config --local user.email "Ваш email из GitHub"
```
Проверить авторов всех коммитов текущей ветки можно командой `git log --format="%h %an <%ae>"`.

## Проверка перед сдачей
Откройте два браузера или обычное окно и окно инкогнито. Зарегистрируйте двух участников. Отправьте сообщение от первого и проверьте, что второй видит отправителя, текст и время. Измените профиль и обновите страницу. Выйдите и проверьте, что чат закрыт. Выполните повторный вход.
